# _template-cardapio

Template base dos cardápios digitais. **Ainda vazio — próximo passo é construir aqui.**

## O que o template deve ter
- Página única mobile-first: capa, categorias, pratos, contato/mapa
- Conteúdo em um arquivo de dados (`cardapio.json`): pratos, preços, fotos, WhatsApp, links de delivery
- Botão "Pedir no WhatsApp" fixo no rodapé, montando a mensagem
- Links para iFood / 99Food / Keeta (exibidos só se preenchidos)
- SEO local: title, description, Open Graph, schema.org `Restaurant`/`Menu`
- Deploy na Vercel
